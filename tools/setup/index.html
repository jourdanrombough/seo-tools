Connect your keys.

The tools pull live search data from DataForSEO and write with Claude. Paste your own keys once. They are tested, then saved on this computer.

This page is for the copy of the tools that runs on your own computer. On a website the keys live in wp-config.php on the server.
1DataForSEOrequired

Sign in at app.dataforseo.com/api-access and copy the API login and API password. The API password is made for you by DataForSEO. It is not the password you sign in with.

2Clauderecommended

Sign in at platform.claude.com, open Settings, then API keys, and choose Create key. The account needs credits (Settings, then Billing). Leave this blank and the tools fall back to their backup AI.
