SEO PITCH DECK GENERATOR
Free from Optimization Theory. Runs on your own computer with your own keys.

START
  Mac:      double-click "Start on Mac.command"
  Windows:  double-click "Start on Windows.bat"
A window opens and stays open while you work. Your browser opens the first-run screen.

FIRST RUN: TWO KEYS
  1. DataForSEO API login and API password   https://app.dataforseo.com/api-access
  2. Claude API key                          https://platform.claude.com/settings/keys
Paste them into the first-run screen and choose "Test and save". They are saved in a file
named .env inside this folder, on this computer only.

THEN
  1. Rates: put in your name, logo and prices.
  2. Build your first deck. Your own domain is a good first run.

IF THE MAC WILL NOT OPEN THE START FILE
  Open System Settings, Privacy & Security, scroll down, choose "Open Anyway".
  Or open Terminal, type  cd  and a space, drag this folder into the window, press Return,
  then type  python3 dev-server.py  and press Return.

IF IT SAYS PYTHON IS MISSING
  Install Python 3 from https://www.python.org/downloads/ (free), then start again.
  On Windows tick "Add python.exe to PATH" in the installer.

STOP
  Close the window that opened when you started the tool.
